# Document Analysis

1. Ground the answer in the supplied files rather than assumptions.
2. Search or retrieve the relevant file passages before making document-specific claims.
3. Preserve page, section, table, or other human-readable locators when available.
4. Distinguish what the document states from your interpretation.
5. If evidence is missing or ambiguous, say so rather than filling the gap.
6. Cite the relevant file evidence when the interface supports citations.
7. For comparisons, apply the same criteria to every source.
