# Repository instructions

- Catat setiap perubahan pada source, UI, konfigurasi, dependency, build, dokumentasi, atau release di `WORKTREE_NOTES.md` dalam tugas yang sama.
- Setiap catatan berisi tanggal, area/perubahan, file atau direktori yang terdampak, hasil verifikasi, dan nama versi/artefak jika ada.
- Catat verifikasi saja bila tugas tidak mengubah source. Tandai pemeriksaan yang belum dijalankan sebagai belum diverifikasi.
- Jangan menyamakan tag upstream AIChat dengan release BotConnector. Sebut sebuah versi sebagai release hanya jika ada bukti tag atau publikasi; bedakan dari installer lokal.
- Jangan masukkan API key, token, isi `.env`, atau rahasia lain ke catatan.
